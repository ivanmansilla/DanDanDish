# DanDanDish
Juego en el que mediante sockets, se conecta el usuario como cliente contra el servidor. Hay 3 opciones a elegir, Disparar, Bloquear o Recargar (una bala). Para poder disparar es necesario tener balas recargadas previamente que se van acumulado por cada recarga. Gana cuando uno dispara y el otro recarga, si los dos disparan a la vez es un empate, y si uno dispara y el otro bloquea se sigue jugando. Codigo realizado junto a un compañero
